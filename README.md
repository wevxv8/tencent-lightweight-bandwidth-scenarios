## 出网、入网、内网带宽，三个数字别混着看

一句话概括：出网带宽等于套餐标称值，是服务器对外服务的速度上限；入网带宽有 10Mbps 保底；内网带宽跟公网完全无关，8 核及以下不低于 1.5Gbps。

**出网带宽（下行）** 就是购买套餐时写着的那个数字。2 核 4G 套餐写 8Mbps，指的就是从服务器流出的数据峰值不超过 8Mbps。这是别人下载你网站内容、调用你接口时共享的总带宽，不是每个访客都能拿到 8Mbps。

**入网带宽（上行方向）** 指数据从外部流入服务器，比如你往服务器上传一个压缩包、用户提交表单。这里的规则有点反直觉：

- 套餐带宽**大于** 10Mbps 时，入网带宽等于套餐带宽；
- 套餐带宽**小于** 10Mbps 时，腾讯云直接给 10Mbps 入网带宽。

也就是说，一台 4Mbps 的入门机器，你往上传文件时能跑到 10Mbps 左右，但别人访问你的站点，出口仍然只有 4Mbps。上传快、下载慢，这个不对称在排查“为什么传文件挺快、网页打开却慢”的时候特别有用。

**内网带宽**是同一地域内实例之间通信的能力。轻量应用服务器 8 核及以下的套餐，内网带宽不低于 1.5Gbps；16 核套餐不低于 2Gbps。这个数字和公网带宽差了两个数量级，所以拿轻量服务器做数据库主从、缓存集群、多机任务分发，内网传输不会成为瓶颈，真正受限的只有公网那一侧。

## 带宽和月流量包是两笔账，流量可能先用完

带宽决定“每秒最多跑多快”，月流量包决定“一个月总共能跑多少”，两者独立计算，超额的部分单独收费。

月流量包统计的只有**出方向流量**，也就是服务器往外发的数据。你上传到服务器的内容、内网之间的传输，都不占流量包。当月用量超过套餐额度，超出部分按量计费，大约 0.8 元/GB 起，不同地域单价不一样。

## 200Mbps 不限流量套餐适合什么场景

它适合短期高并发、视频和大文件传输这类“流量大但不需要长期稳定跑满”的用途，不适合对带宽稳定性有硬要求的生产业务。

200Mbps 的含义是峰值能冲到 200Mbps，配合不限流量的政策，做活动页、临时下载站、直播推流中转都很合适。但要注意，这个带宽是共享的，高峰期可能被降速，官方并没有承诺任何时刻都能跑满 200Mbps。如果你的业务是 7×24 小时的视频分发，或者对下载速度有 SLA 要求，固定带宽的云服务器 CVM 更合适；如果只是一个月里集中几天扛流量，200Mbps 不限流量款的性价比明显更高。

## 按使用场景反推，你需要多少带宽

与其纠结档位表，不如从你的站每天要发多少数据倒推。下面四种情况覆盖了大多数轻量服务器的实际用途。

**纯文字博客、企业展示站**：一篇文章的 HTML 加样式通常几十 KB，一天 500 个 PV 也就消耗几十 MB。1 核 2G + 5Mbps 这档完全够用，200GB 到 500GB 的流量包能用很久。

**图文站、小程序后端**：图片单张 200–500KB，一天 2000 PV 可能跑掉 1–2GB 流量。2 核 4G + 8Mbps 搭配 1200GB 流量包是比较稳的组合，图片多的话记得开 Gzip 和 WebP，能省下三到七成流量。

**图床、软件下载、短视频**：单次请求就是几 MB 到几十 MB，4Mbps 的出口会让用户等到怀疑人生。这种场景要么直接上 200Mbps 不限流量款，要么把静态资源放对象存储加 CDN，让服务器只负责逻辑。

**多机内网通信**：如果几台轻量服务器在同一地域跑集群，公网带宽选最低档都行，因为内网保底 1.5Gbps，真正吃带宽的活都在内网完成。

## 常见问题

**6Mbps 带宽的实际下载速度是多少？**
理论峰值约 0.75MB/s，也就是 768KB/s 左右。实际速度受线路质量、并发数和对方网络影响，通常会低于这个值。

**入网流量要额外付费吗？**
不用。月流量包只统计出方向流量，用户上传到你服务器的数据不计入额度，也不额外收费。

**流量包用超了会直接停机吗？**
不会停机，超出部分按量计费，大约 0.8 元/GB 起，不同地域单价不同。建议在云监控里设置 80% 的流量告警，避免月底才发现超额。

**香港、新加坡节点的带宽比内地高吗？**
是的。同一产品线下，海外节点的带宽档位明显更高，国际站页面上的入门型就有 20Mbps，通用型 30Mbps。如果你的用户主要在境外，或者业务对带宽需求大但对境内访问速度不敏感，海外节点值得优先考虑。

**内网带宽 1.5Gbps 对我有什么用？**
如果你只跑单机网站，基本用不上。但只要你有多台同地域实例互相传数据、做主从复制或分布式任务，内网带宽就是决定效率的关键，这时候公网带宽反而可以选低档。
